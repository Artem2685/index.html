📏 Расчет рамки (Трапеция)

Параллельно нижнему Перпендикуляр между основаниями 0 = левый угол прямой. >0 = сдвиг вправо, <0 = сдвиг влево
Проверьте введенные данные. Стороны не могут быть отрицательными.

Размеры для резки рамки:

Нижняя сторона: 0 мм
Правая сторона: 0 мм
Верхняя сторона: 0 мм
Левая сторона: 0 мм
Общая длина (в круг): 0 мм
